Krea 2 prompt reference

Pose Sheet

Pose prompts sorted by shoot. Type your LoRA trigger once and every prompt fills it in, then copy any frame with one click. Also available inside ComfyUI as a sidebar and a node.

Last updated ·

How to use this sheet

The controls

  • Trigger fills your LoRA trigger into every prompt.
  • Style off strips the look words (photo type, film, grain, palette) so a LoRA supplies the look.
  • Copy set copies a whole set, one prompt per line, ready for a prompt list in ComfyUI.
  • Build a person describes who is in the shot. Person adds them to every prompt.
  • ☆ saves a frame to your Starred tab in this browser.

Settings that work

  • Krea 2 Turbo: 8 steps.
  • CFG 1.0 on the stock ComfyUI KSampler.
  • Render at full size (trained up to 2048×2048) instead of upscaling.
  • Match the canvas to the shot: wide for side views, tall for full length.

In ComfyUI

  • Install Krea Pose Sheet from ComfyUI Manager, or clone the GitHub repo into custom_nodes.
  • Open the Pose Sheet tab in the left sidebar.
  • Add the Krea Pose Prompt node to feed prompts straight into your text encoder.
